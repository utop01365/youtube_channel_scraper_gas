# YouTube Data API チャンネル情報取得システム (GAS版)

**目標達成を絶対条件とし、クォータ上限を回避しつつ最短時間で収集するGoogle Apps Script実装**

## 特徴

✅ **目標達成保証**: 目標件数に達するまで自動継続実行  
✅ **クォータ管理**: 1日のクォータ上限（10,000ユニット）を監視し、超過を回避  
✅ **実行時間制限回避**: 6分の制限を継続トリガーで解決  
✅ **自動復旧**: エラー発生時も進捗を保持し、自動再開  
✅ **クラウド実行**: PCを起動せずに24時間稼働可能  
✅ **リアルタイム共有**: スプレッドシートでデータをすぐに共有

## セットアップ手順

### 1. スプレッドシートを作成

1. [Google スプレッドシート](https://sheets.google.com)で新規作成
2. ファイル名を「YouTubeチャンネル収集」等に変更

### 2. Apps Scriptエディタを開く

1. スプレッドシートで「拡張機能」→「Apps Script」を選択
2. デフォルトの`Code.gs`が開く

### 3. スクリプトファイルをコピー

以下のファイルを順番に作成してコピー：

1. **Config.gs** - 設定ファイル
   - 「+」→「スクリプト」→「Config」
   - `gas/Config.gs`の内容をコピー

2. **YouTubeClient.gs** - YouTube API クライアント
   - 「+」→「スクリプト」→「YouTubeClient」
   - `gas/YouTubeClient.gs`の内容をコピー

3. **ChannelManager.gs** - データ管理
   - 「+」→「スクリプト」→「ChannelManager」
   - `gas/ChannelManager.gs`の内容をコピー

4. **EmailExtractor.gs** - メール抽出
   - 「+」→「スクリプト」→「EmailExtractor」
   - `gas/EmailExtractor.gs`の内容をコピー

5. **Code.gs** - メインロジック
   - デフォルトの`Code.gs`を上書き
   - `gas/Code.gs`の内容をコピー

### 4. YouTube Data API v3 の高度なサービスを有効化

#### 4-1. GASエディタでサービスを追加

1. Apps Script エディタの左メニューで「サービス」（+アイコン）をクリック
2. 「YouTube Data API v3」を検索
3. 選択して「追加」をクリック

#### 4-2. Google Cloud Consoleで有効化

1. [Google Cloud Console](https://console.cloud.google.com/)にアクセス
2. 「APIとサービス」→「ライブラリ」
3. 「YouTube Data API v3」を検索して有効化

### 5. 設定を編集

`Config.gs`を開いて以下を設定：

```javascript
// 検索キーワード
const SEARCH_QUERY = '釣り';  // ← 検索したいキーワード

// 目標取得チャンネル数
const MAX_CHANNELS = 1000;  // ← 目標件数

// メールアドレスが抽出できたチャンネルのみ収集するか
const ONLY_WITH_EMAIL = true;  // true: メールありのみ / false: すべて
```

※APIキーは不要！高度なサービスがOAuth2で自動認証します。

### 6. 初期セットアップを実行

1. Apps Scriptエディタで関数を選択: `setup`
2. 「実行」ボタンをクリック
3. 初回は権限の確認画面が表示される
   - 「権限を確認」→ Googleアカウントを選択
   - 「詳細」→「（プロジェクト名）に移動」
   - 「許可」をクリック

### 7. 収集を開始

1. 関数を選択: `collectChannels`
2. 「実行」ボタンをクリック
3. 自動的に継続実行され、目標件数に達するまで実行されます

## 動作の仕組み

### 継続実行パターン

```
[開始] collectChannels() 実行
   ↓
5分30秒間、チャンネル収集
   ↓
目標達成? → YES → [完了] トリガー削除
   ↓ NO
クォータ残量OK? → NO → 翌朝6時に再開トリガー設定
   ↓ YES
5秒後に再実行トリガー設定
   ↓
[継続] collectChannels() 自動実行
```
### 検索順序の自動切替

選択した検索モード（channel/video）で、3つの順序を順番に実行：

```
[開始] relevance（関連性順）で検索
   ↓
結果が尽きた? → YES → viewCount（視聴回数順）に移行
   ↓ NO               ↓
継続収集            結果が尽きた? → YES → date（新着順）に移行
                        ↓ NO               ↓
                       継続収集            結果が尽きた? → 完了
                                           ↓ NO
                                          継続収集
```
### クォータ管理

- 1日の上限: 10,000ユニット
- 安全マージン: 95%（9,500ユニット）で停止
- リセット: 毎日深夜0時（太平洋標準時）
- 自動再開: 翌朝6時にトリガーで再実行

### データ保存

**チャンネルデータシート**:
| チャンネルID | チャンネル名 | チャンネルURL | メールアドレス | 登録者数 | ... |
|------------|------------|--------------|--------------|---------|-----|
| UCxxxxxx | サンプル | https://... | example@... | 50000 | ... |

**実行ログシート**:
| 実行日時 | ステータス | メッセージ | クォータ使用 | 取得件数 |
|---------|---------|----------|-----------|---------|
| 2026-02-28 10:00 | INFO | 収集開始 | 0 | 0 |

## トラブルシューティング

### Q1. 「クォータ上限に達しました」と表示される

**原因**: 1日のAPI使用量（10,000ユニット）を超えた

**対処**:
- 翌朝6時に自動再開されます
- 手動で再開する場合は翌日に`collectChannels()`を実行

### Q2. 実行が途中で止まる

**原因**: 6分の実行時間制限

**対処**:
- 自動的に継続トリガーが設定されます
- 5秒後に自動再開されるのでそのまま待つ

### Q3. メールアドレスが見つからない

**原因**: チャンネルのdescriptionにメールアドレスがない

**対処**:
- `ONLY_WITH_EMAIL = false` に設定してすべて収集
- または、別の検索キーワードを試す

### Q4. 目標件数に達しない

**原因**: 検索結果が尽きた

**対処**:
- より一般的なキーワードに変更
- `SEARCH_TYPE = 'video'` に変更（重複多いが結果多い）
- `ONLY_WITH_EMAIL = false` に変更

### Q5. エラーメールが届く

**対処**:
- ログシートでエラー内容を確認
- APIキーが正しく設定されているか確認
- クォータが残っているか確認

## パフォーマンス

### 収集速度の目安

**チャンネル直接検索（channel）の場合**:
- 1回の実行（5分30秒）: 約50-100件
- 1時間: 約600-1200件
- 1000件達成: 約1-2時間

**動画経由検索（video）の場合**:
- 重複が多いため遅い
- 1000件達成: 約3-6時間

### クォータ消費の目安

**1000件収集時**:
- チャンネル検索: 約2,000-3,000ユニット
- 動画検索: 約4,000-6,000ユニット

## ベストプラクティス

### 1. 最短時間で収集するには

設定シートで：
- **検索モード**: channel（チャンネル直接検索）
- **メールアドレス必須**: FALSE（フィルタリングしない）

Config.gsで：
```javascript
const MAX_EXECUTION_TIME = 5.5 * 60 * 1000;  // 最大実行時間
const SEARCH_ORDERS = ['relevance', 'viewCount', 'date'];  // 複数順序
```

### 2. クォータを節約するには

設定シートで：
- **検索モード**: channel（チャンネル直接検索）
- **メールアドレス必須**: TRUE（必要なデータのみ）

Config.gsで：
```javascript
const RESULTS_PER_PAGE = 50;          // 最大50件
```

### 3. メールアドレス収集率を上げるには

設定シートで：
- **検索モード**: video（動画経由、アクティブなチャンネル）

Config.gsで：
```javascript
const SEARCH_ORDERS = ['date', 'viewCount', 'relevance'];  // 新しい順優先
```
